Trackulate

Pick up passengers along the line. The crossing only opens for the exact count.

How to Play

  1. Your train starts with a few passengers.
  2. Tap stops to pick a route. Each stop you pass through changes the count.
  3. Every route ends at the same last stop, then a crossing.
  4. Arrive with the exact count and the gate lifts. Anything else derails you.
  5. You get 3 trains. Everyone gets the same board each day.
